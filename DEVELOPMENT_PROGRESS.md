# Доработка платформы — 10 октября 2026

Код всех четырёх этапов реализован. Последние проверки: ESLint, тесты сценариев и production build (включая TypeScript) успешны. Публикация выполняется через main → Netlify; после сборки проверяются публичные маршруты, статистические данные и PDF трёх типов. Секреты не добавляются в репозиторий.

## Этап 1 — выполнен, проверен lint / test:study / production build
- Выборка: один запрос на гипотезу распределения, характеристики генерируются локально; отдельного AI-запроса на человека нет.
- Опрос: до 20 профилей в пакете вместо 5, адаптация размера пакета к длине вариантов.
- Компактный профиль без повторяющихся темы/вопроса, пустого ответа, нерелевантных интересов/ценностей.
- Интервью: до восьми вопросов за запрос вместо одного; сохранённая история учитывается, уже полученные ответы не повторяются.
- Последовательное выполнение (параллельность 1), прогресс, отмена, сохранение после пакета.
- Оценка токенов, бюджет запросов/токенов для связанного исследования. Счётчик запросов включает ошибки. Полученные токены — usage провайдера, выборка — консервативная оценка 3000.
- Серверный AI_MAX_REQUEST_TOKENS (60000 по умолчанию). Бюджет проекта хранится в браузере, это контроль рабочего процесса, а не общий защищённый лимит аккаунта. Бесплатная маршрутизация OpenRouter запрещает платный fallback.
- Ответы разных участников не копируются и не кэшируются. Сохранённые результаты одного проекта служат кэшем при продолжении.
- Для N=100 и трёх вопросов интервью K=10: опрос 20→5 запросов, интервью 30→10; всего с выборкой и отчётом 52→17 (67% меньше). Это расчёт, не измерение токенов; реальные usage зависят от модели, вопросов и reasoning.

## Финальные исправления и проверки

- Бюджет теперь применяется и к старым количественным запросам. Анализ на карте можно отменить; каждый полученный ответ сохраняется сразу, повторение продолжает недостающие. Прогресс отображает реальные операции.
- Исправлена повторная загрузка проекта/формы при изменении ID/type на том же маршруте /study.
- В старом количественном отчёте цитаты фильтруются по дословному совпадению с интервью; распределение задаётся кодом. Фиктивные источники, заранее прописанные числа/ответы в результатах и чате сегментов убраны.
- Исправлено ложное тематическое совпадение аббревиатуры «ИИ» с окончанием слова «России».
- Дополнительные тесты: выборка 20 человек требует одного запроса, фильтры пола/возраста соблюдены, неподдерживаемая рамка отклоняется до запроса, отмена не заменяется резервными результатами, бюджет запрещает лишний запрос, выдуманная цитата исключается.
- Локальные HTTP-проверки 13 страниц с общим меню: 200; PDF всех трёх типов: 200; неполный смешанный: 400; предварительный качественный: 200; чужой ID: 400. Источник содержит 24 валидные ячейки.
- Живые нейтральные проверки: опрос 20 уникальных ID — 2118 токенов; два вопроса интервью — 1088; отчёт с темами — 3727. Это отдельные измерения, а не гарантированный расход любого проекта. PDF не требует AI-запроса.
- Данные проектов хранятся в текущем браузере; облачная синхронизация не добавлена. Автоматическая калибровка мнений не включена без сопоставимого вопроса и совокупности. Бесплатная общая квота OpenRouter может исчерпаться независимо от бюджета проекта.

## Netlify

Обязательные AI_PROVIDER, OPENROUTER_MODEL и секретный OPENROUTER_API_KEY уже настроены; новых обязательных переменных нет. Опционально: AI_MAX_REQUEST_TOKENS, OPENROUTER_REASONING_TOKENS. Для платных xAI/Groq оценка цены использует AI_INPUT_USD_PER_MILLION и AI_OUTPUT_USD_PER_MILLION. PDF использует встроенные шрифты; ключи отсутствуют в клиентском JavaScript.

## Провайдеры
Текущий OpenRouter Nemotron free: уже настроен, OpenAI-совместимый JSON API, свободный дневной лимит 50 запросов при отсутствии пополнений, может перегружаться. Русский следует проверять на сценариях платформы, рейтинг качества не измерен.
Gemini API: для некоторых моделей есть бесплатный API, JSON поддерживается; квоты зависят от модели/проекта и доступны в AI Studio. Нужен отдельный ключ; автоматический переход на оплату недопустим. Не подключён без ключа и проверки доступности аккаунта/региона.
Groq: сохранена поддержка через AI_PROVIDER=groq, GROQ_API_KEY/GROQ_MODEL; квоты модели смотреть в console.groq.com. Grok: сохранён xai, XAI_API_KEY/XAI_MODEL, текущий аккаунт требует кредитов.
